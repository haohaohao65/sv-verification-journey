# FIFO Specification

## 1. 基本参数

- DATA_WIDTH = 8
- DEPTH = 16
- 类型：同步 FIFO

## 2. 输入接口

| 信号 | 位宽 | 说明 |
|---|---:|---|
| clk | 1 | 时钟 |
| rst_n | 1 | 低有效复位 |
| wr_en | 1 | 写使能 |
| rd_en | 1 | 读使能 |
| wr_data | 8 | 写入数据 |

## 3. 输出接口

| 信号 | 位宽 | 说明 |
|---|---:|---|
| rd_data | 8 | 读出数据 |
| full | 1 | FIFO 满 |
| empty | 1 | FIFO 空 |

## 4. 行为定义

### 写操作
FIFO 未满且 wr_en=1 时，写入 wr_data。

### 读操作
FIFO 非空且 rd_en=1 时，读出最先写入的数据。

### FIFO 满
full=1 时，暂不接受新的写操作。

### FIFO 空
empty=1 时，暂不产生有效读操作。

### 同时读写
FIFO 处于正常状态时，允许同时读写。

## 5. 核心验证目标

1. 数据能够正确写入 FIFO。
2. 数据能够正确读出。
3. 保证 FIFO First-In First-Out。
4. 验证 FIFO 空状态。
5. 验证 FIFO 满状态。
6. 验证满状态下继续写入的行为。
7. 验证空状态下继续读取的行为。
8. 验证正常状态下同时读写。
9. 验证复位行为。
